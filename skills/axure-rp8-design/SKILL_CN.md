# Axure RP 8 可见窗口设计工作流

本 Skill 适用于本仓库的 Windows 适配器。项目目标为 Axure RP 8.0–8.1，但当前适配器仅针对 Axure RP 8.0.0.3400 验证。其他 RP8 构建、RP9 及以上版本，以及非 Windows 主机，均须单独移植和验证后才能使用。

## 安全工作流

1. 请用户通过专用启动器打开现有 .rp 文件，或使用已经获授权的运行实例。
2. 调用 status，确认宿主已就绪并识别当前工作副本路径。不要仅凭旧的 session.json 心跳判断进程仍在运行。
3. 读取 pages 和当前页的 widgets 或 page.content；通过 GUID 定位对象，不要只依赖显示名称。
4. 每次只通过 live/live_cli.py 发送一条范围明确的原生命令。中文或多行内容使用 JSON 文件。
5. 命令超时后，先检查对应请求与结果文件，再决定是否重试修改操作。
6. 修改当前页后，切换页面前先保存。另存为必须使用新 .rp 路径；适配器会拒绝已存在的目标文件。
7. 检查响应并查看可见画布。需要确认持久化时，在另一个 RP8 读取实例中重新打开保存文件，比较页面/元件 ID 和交互。
8. 明确报告不支持的功能。动态面板状态、中继器、自适应视图和任意 Axure 表达式语法不在当前实现范围内。

## 操作限制

- 启动器会把源 .rp 复制到会话专用工作目录。只编辑该副本。
- 可见 RP8 窗口不会置顶。适配器不模拟鼠标/键盘，也不注入剪贴板内容。
- 如果专用进程已经存在，启动器会复用它，不会激活窗口或切换文件。
- 宿主会校验 Axure RP 8.0.0.3400 指定安装文件的哈希。绝不绕过不匹配检查。
- 有未保存修改时不要强制关闭 RP8。存在未保存修改时，close 会拒绝关闭。
- 运行期请求和结果可能含有用户设计文本；不要把它们放进公开提交。
