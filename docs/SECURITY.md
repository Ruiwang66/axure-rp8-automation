# 安全与隐私

- 使用启动器指定的工作副本；保留原始 `.rp` 作为回退版本。
- `live/session.json`、请求/响应 JSON、截图和导出文件可能含有原型文字、GUID、个人文件路径和窗口状态。只保存在本机，不要作为 issue 附件或 Git 提交上传。
- 仓库没有 Axure EXE、DLL、配置、图标、个人 `.rp` 项目或预览截图。使用者应自行安装并获授权使用 Axure RP 8。
- 版本 SHA-256 检查保护反射式内部调用不落到不同 Axure 构建上。遇到不匹配时停止，不要修改期望哈希来强制启动。
- 调整交互前读取现有用例。`interaction.replaceActions` 会替换目标用例的全部动作。
- `save` 的另存为拒绝覆盖已存在的目标路径；请先选新文件名。
- 该程序会按 Axure 正常方式读写自己的用户设置目录。不要以管理员权限运行，除非你的 Axure 安装目录确实要求该权限。

如要公开提交问题，请先删除请求日志、截图、工程名和用户名等个人信息，并仅附最小复现样例。
